# 品質チェックツール 詳細

`CLAUDE.md` にはツール名・用途一行・コマンドだけを置き、**検出の中身と較正の履歴はこのファイルに集約**している。

**この表が正本**。CLAUDE.md の表の各行はこの表の同名行からの抜粋 (部分文字列)。**検査を足したり較正を書き足すときはこのファイルの表に書き、CLAUDE.md には規則を述べる文だけを抜く**。

**読むべきとき**
- QA / lint が警告を出し、それが真陽性か偽陽性かを判断するとき
- 「この症状はどの検査が捕まえるはずだったか」を遡るとき
- 新しい検査を足すとき (既存の較正方法と閾値の決め方に倣う)
- 出荷前の最終確認

**大原則** (`CLAUDE.md` の QA 運用にも記載)
- lint の警告を「STT の揺れ」「検証不可」で退けない。**警告は既に一つの証拠**であり、否定する側に反証の義務がある
- 決定論チェックの沈黙を検証の代わりにしない (bbox 重なりは「読めるか」の代理指標にすぎない)
- 検査は記述でなくコードで強制する。検査を足したら同じ変更で pipeline / smoke_test に配線する
