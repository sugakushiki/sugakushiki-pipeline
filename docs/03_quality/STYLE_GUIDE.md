## 1. トーン・語り口

### 基調

サイモン・シン『フェルマーの最終定理』の語り口。抑制的で品があり、事実の積み重ねで感動を生むスタイル。

**温度感**：「賢い友人が居酒屋で熱く語っている」くらい

### 語り口の基準

| 項目 | 基準 |
|---|---|
| 文体 | **ですます調**。堅すぎない敬語ベース。専門用語は文脈で理解できるように |
| 感嘆符 | 1スクリプトに2〜3回まで |
| 禁止表現 | 「ヤバい」「すごすぎる」「衝撃」等の煽り語 |
| 許容する強調 | 「ここが面白いのは」「注目すべきは」等の抑制的な表現 |
| 数学者の描写 | 敬意はあるが神格化しない。失敗や人間的な弱さも等しく描く |
| 数学の説明 | 数式を「導出する」のではなく「意味を語る」スタンス |

### 文字数ターゲット

**290字/分**で `target_duration_minutes` から動的計算。

| 目標尺 | 文字数範囲 |
|---|---|
| 10分 | 2,600〜3,200字 |
| 11分 | 2,900〜3,500字 |
| 13分 | 3,350〜4,150字 |

### タイトル・サムネイル

本編より少し温度を上げるが、煽りではなく「好奇心の喚起」に留める。

| OK | NG |
|---|---|
| ガロア ── 20歳が見抜いた方程式の対称性 | 20歳で死んだ天才がヤバすぎた!! |
| 5次方程式はなぜ解けないのか | 【衝撃】絶対に解けない方程式の真実 |

### タイトル形式

`[数学者名] ── [サブタイトル]` で統一。全角ダッシュ2本（──）で区切る。

NHKドキュメンタリーのナレーターが参考イメージ。やや遅め、感情を込めすぎない朗読調。

### narration_speech（音声読み替え）

数式記号（²√−π等）を含むナレーションでは、`narration_speech` フィールドに読み下し文を設定する。VOICEVOXには `narration_speech` を送り、字幕には `narration`（元テキスト）を表示する。

```json
{
  "narration": ["x²−2=0 という方程式を考えます。"],
  "narration_speech": ["xの2乗マイナス2イコール0 という方程式を考えます。"]
}
```

- `auto_generate_narration_speech()` が非標準文字をスキャンし、未設定ならルールベースで自動生成
- VOICEVOX辞書は文脈依存の読みに不向き。narration_speechが確実な方法
- 残留チェック: 変換後にまだ記号が残っていれば警告

### narration_speech 必須適用ルール（生成・編集時）

VOICEVOX 誤読を構造的に予防する。moriarty 例エピソードで顕在化した問題への構造的対策。

#### 複合語末尾「値」→「ち」読み

| narration (字幕) | narration_speech (音声) | 誤読 |
|---|---|---|
| 観測値 | かんそくち | かんそくあたい |
| 絶対値 | ぜったいち | ぜったいあたい |
| 理論値 | りろんち | りろんあたい |
| 期待値 | きたいち | きたいあたい |
| 最大値・最小値・平均値・固有値 | さいだいち / さいしょうち / へいきんち / こゆうち | あたい |

**重要**: narration が「観測値」なら narration_speech は「かんそくち」と完全ひらがな化する。**「観測あたい」「絶対あたい」のような kanji/kana 混合形は誤り** (運用知見: moriarty 例エピソードで顕在化)。

例外: 単独の「値」（「πの値」「f(x)の値」）のみ「あたい」読み。

#### 分数「N分のM」→「Nぶんのいち/に」読み

VOICEVOX のデフォルトは「N分のM」を時間の「分(ふん)」と混同して「にふんのいち」と誤読する。完全ひらがな化必須。

| narration (字幕) | narration_speech (音声) |
|---|---|
| 2分の1 | にぶんのいち |
| 3分の2 | さんぶんのに |
| 4分の3 | よんぶんのさん |

`audio_generator._convert_fractions()` で `(\d+)分の(\d+)` → kana 自動変換 (1-20 の denominator/numerator は対応、外側は数字のままで「ぶんの」のみ ひらがな化)。

#### 修辞的「否」→「いな」読み

| narration (字幕) | narration_speech (音声) |
|---|---|
| 答えは「否」です | 答えは「いな」です |
| P は否である | P はいなである |

**「ひ」読みは熟語専用**: 否定 (ひてい)、賛否 (さんぴ)、否決 (ひけつ)。単独・修辞用法は「いな」。

#### 数式 `A/B` の音声化

- **単純な分数**: 「BぶんのA」(denominator-first 読み)
- **複雑な式 (例: `α(α-1)/2!`)**: narration 自体から数式を外し、文章で説明する（「展開項は 2 の階乗を分母に持つ」等）。具体的な式は visual (formula_display) で表示
- **避ける**: narration_speech に「A 割る B」のような直訳を入れない（「割る」の挿入が機械的に聞こえる）

#### 既知の誤読パターン

| narration (字幕) | narration_speech (音声) | 誤読 |
|---|---|---|
| 多角形・角形 | たかくけい・かくけい | カクガタ |
| 空集合 | くうしゅうごう | そらしゅうごう |
| 流率法 | りゅうりつほう | りゅうりつほう (英語名 fluxion) は使わない |
| 今日 (現代の意味) | こんにち | キョウ |
| ヨーロッパ中 | ヨーロッパじゅう | ちゅう |
| 嫉妬深い | しっとぶかい | しっとふかい |

これらは `audio_generator._MISREADING_CATEGORIES` に登録済。新規 ep でも自動 catch。

### APIコード

query["pauseLengthScale"] = 1.3

| 用途 | フォント |
|---|---|
| 日本語テキスト | BIZ UDMincho |
| 数字・数式 | MathTex（LaTeX） |

### テキスト描画ルール

- 日本語と数式の混在：`styled_text` ヘルパー関数で分割描画
- MathTexのサイズ調整：`match_height` + `scale(0.85)` で日本語テキストと高さを合わせる
- アニメーション：**FadeIn を使用**（Write は描画タイミングがずれるため不可）
- Y座標範囲: 全オブジェクトが y = −2.0 〜 +3.3 の範囲内（字幕クリアランス: y ≈ −2.2）
- 字幕はパイプラインStep 3で別途生成。テンプレート内でキャプションを入れない

### styled_text ヘルパー関数

```python
FONT = "BIZ UDMincho"

def styled_text(*parts, font_size=28):
    """("テキスト", "text"/"math") のタプルを受け取り横に並べる"""
    group = VGroup()
    text_ref = None
    for content, kind in parts:
        if kind == "math":
            t = MathTex(content, font_size=font_size)
        else:
            t = Text(content, font=FONT, font_size=font_size)
            if text_ref is None:
                text_ref = t
        group.add(t)
    if text_ref is not None:
        for item in group:
            if isinstance(item, MathTex):
                item.match_height(text_ref)
                item.scale(0.85)
    group.arrange(RIGHT, buff=0.15)
    return group
```

## 6. 出典・参考文献

### 方針

各動画のYouTube概要欄に主要参考文献とデータ出典を記載する。ターゲット層（エンジニア・数学好き）は出典を重視するため、信頼性の担保とチャンネルの品格維持の両面で必須。

### 記載項目

| 項目 | 記載場所 | 必須/任意 |
|---|---|---|
| 主要参考文献（書籍・論文） | 概要欄 | 必須 |
| データ出典（統計値・データセット） | 概要欄 | 必須 |
| 映像素材のライセンス | 概要欄 | 必須（VOICEVOX等） |
| 事実関係に議論がある場合の注記 | 概要欄 or ナレーション内 | 必須 |

### フォーマット

`credits_generator.py` がscene_definition.jsonの`description`ブロック（intro/chapter_subtitles/tags）と`wikimedia_credits.json`から自動生成する。

```
【音声合成】
VOICEVOX:青山龍星

【BGM】
Angel's Dream - Aakash Gandhi（YouTube Audio Library）

【映像素材】
AI生成画像：Google Gemini
数式アニメーション：Manim Community
地図データ：Natural Earth（パブリックドメイン）

【写真クレジット】
（Wikimediaから自動取得）

【主要参考文献】
- 著者名, "書名" (出版年)
- ウェブサイト名 (URL)
```

### ナレーション内での言及

数値や引用は「〜と言われています」「〜によると」等で典拠を示唆する。ナレーション中にいちいち書名を読み上げる必要はない。概要欄で詳細を確認できる旨をエンドカードで案内する。

### 事実確認の原則

- 歴史的主張はWeb検索で検証してからナレーションに入れる
- LLMの推論を鵜呑みにしない（過去にFRS序列、年齢、p(100)の桁数等で修正あり）
- `episode_config.json` の `verified_facts` と `common_errors_to_avoid` に検証結果を記録
