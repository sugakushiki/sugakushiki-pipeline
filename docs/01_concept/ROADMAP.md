## Phase 1：MVPパイプライン構築（4〜5週末）

**目的**：データ→動画の一気通貫フローを自動化する

| タスク | 内容 |
|---|---|
| データ層 | Wikidata/MacTutorからのデータ取得パイプライン構築 |
| スクリプト生成 | Claude/Gemini APIでJSON→構造化スクリプト |
| 音声合成 | スクリプト→VOICEVOX自動変換 |
| ビジュアル | シーン指示→Manim + Pillow自動生成 |
| 動画合成 | FFmpegでの全素材統合 + 字幕生成の自動化 |

**設計方針**：汎用層とジャンル固有層の分離を意識。ただし過度な抽象化は避けてまず動くものを優先

**完了基準**：JSONデータを入力すると8〜10分の動画が1本出力される状態（品質は粗くてよい）

### 品質チェック自動化（マルチエージェントQA）

視聴者満足度（完視聴率）を最大化するため、パイプラインの各段階に8エージェント × 4ゲートのQAパイプラインを構築する。スクリプトだけでなく、画像・音声・最終アセンブリの各段階でチェックを行い、ターゲット（数学好き一般層 × エンジニア・DS層）への最適化とチャンネルの差別化（ゆっくり解説系との品質差、サイモン・シン的トーン）を担保する。

| Gate | タイミング | エージェント | 実装優先度 |
|---|---|---|---|
| Gate 1 | スクリプト生成後 | ① ストーリーアーキテクト（構成・フック・現代技術接続） | 第2弾 |
|  |  | ② ファクトチェッカー（事実確認・出典検証） | 第1弾 |
|  |  | ③ スタイルチェッカー（トーン・禁止語彙・説明スタンス） | 第3弾 |
|  |  | ④ テンポアナライザー（映像多様性・尺バランス） | 第2弾 |
| Gate 2 | 画像生成後 | ⑤ ビジュアル品質エージェント（画風・時代考証・一貫性） | 第1弾 |
| Gate 3 | 音声生成後 | ⑥ 読み上げ検証エージェント（Whisper STT差分検出） | 将来 |
| Gate 4 | 最終アセンブリ後 | ⑦ 最終レビュアー（スタブ残存・字幕超過・統合品質） | 第3弾 |
|  |  | ⑧ 出典マネージャー（概要欄テキスト生成） | 第3弾 |

**詳細設計**: `docs/QA_PIPELINE.md` を参照。
