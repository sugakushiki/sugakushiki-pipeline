# 数学史記 プロジェクト構想

## プロジェクト概要

**数学史記（すうがくしき）** は、生成AIを活用して数学史をテーマとしたドキュメンタリー動画を制作するプロジェクト。

動画制作パイプラインの構築自体をエンジニアリングプロジェクトとして位置づけ、動画コンテンツはパイプラインのアウトプットとする。

## コンセプト

**「数学者の人生を通して、数学の面白さを知る」**

数学者の人生（ストーリー）と数学的業績（内容）を1本の動画で描くハイブリッド型。NHKスペシャル的な知的ドキュメンタリーのトーンで、人物と数学を等しく扱う。

## ポジション

**日本語唯一の数学史ドキュメンタリーチャンネル**

日本語YouTubeの数学系は受験数学に偏っており、「数学者の人生×数学的業績」をドキュメンタリー品質で継続的に発信するチャンネルは存在しない（2026年2月時点）。

## ターゲット

数学好き一般層（高校〜大学教養レベルの社会人・理系大学生）とエンジニア・DS層（業務で数学を使うが歴史的背景は知らない層）の重なり。

## 動画構造

尺の canonical な値は [`docs/02_pipeline/VIDEO_SPEC.md`](../02_pipeline/VIDEO_SPEC.md) が唯一の出典。
ここでは**構成比**だけを示す（尺の数値をこの表にも書くと 2 つ目の出典ができて片方が古くなるため）。

| パート | 配分 | 内容 |
|---|---|---|
| 導入（フック） | 短く（1分前後） | 視聴者を引き込む意外な事実やエピソード |
| 人物パート | 本編のおよそ半分 | 時代背景、生い立ち、転機となるエピソード |
| 数学パート | 本編のおよそ半分 | 代表的業績を直感的に解説。数式は最小限 |
| 締め | 短く（1分前後） | 数学史における位置づけ |

人物パートは業績の列挙で終わらせず、性格・苦悩・人間味・個人的なエピソードを一次資料で
裏取りして入れる。視聴者は数式よりも人物の物語に引き込まれる。

## コンテンツの2層構造

- **通常回**（テーマフォーカス）：1つのテーマを中心人物のストーリーとともに描く。パイプラインで量産可能
- **深掘り回**（分野の発展フォーカス）：1テーマを複数の数学者が時代を超えて追う。通常回の枠を超える尺を許容する例外枠（上限は VIDEO_SPEC 参照）

## 技術パイプライン

```
JSON(数学者データ)
  → Claude/Gemini API (スクリプト生成 + シーン指示)
  → VOICEVOX (音声合成) + Manim (数式アニメ) + 画像生成AI (肖像・背景)
  → FFmpeg (動画合成 + 字幕)
  → YouTube API (アップロード)
```

## 多層アウトプット戦略

| 層 | 内容 | 役割 |
|---|---|---|
| 表のコンテンツ | YouTube動画 | 視聴者獲得・ブランド認知 |
| 中間層 | note（スクリプト + 制作過程） | 教育者・学生層へのリーチ |
| 技術層 | GitHub（データセット + パイプラインコード） | エンジニアコミュニティでの認知 |
| 拡散層 | Zenn/Qiita技術記事（任意） | 最もバズる可能性が高い |

## 核心的な結論

> 動画そのものの収益より、「動画を自動生成できる仕組みを作った」というストーリーの方が、キャリア的にもブランディング的にも価値が高い。

## 競合優位性

- **データ基盤**：構造化された数学者データ（蓄積型、後発は追いつきにくい）
- **数学的バックグラウンド**：数学修士（初等整数論）の専門知識
- **自動化パイプライン**：LLM活用の動画制作自動化
- **ファーストムーバー**：日本語数学史ドキュメンタリーの先駆者
